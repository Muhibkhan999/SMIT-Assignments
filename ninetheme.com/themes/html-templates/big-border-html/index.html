  • Apple Clone

    I have developed an App Store clone, a platform designed to replicate the core functionalities and user experience of the official Apple App Store. This clone features a user-friendly interface that allows users to browse, search, and download applications seamlessly.

  • Sunzine Clone

    Sunzine Photo Gallery is a dynamic and visually engaging platform designed to showcase and share stunning photography. This gallery serves as a digital space for photographers, artists, and enthusiasts to display their work, allowing users to explore a diverse collection of images across various categories.

  • Gmail-Clone

    Gmail Clone is a robust email platform that I developed, inspired by the original Gmail service. This application offers users a seamless and efficient way to communicate through email, featuring an intuitive interface and a range of powerful functionalities.

  • Facebook Login Page

    Facebook Login Page Clone is a user-friendly authentication platform that I developed, inspired by the original Facebook login interface. This clone allows users to securely access their accounts and manage their profiles with ease.

  • Salt n Pepper

    Salt n Pepper Clone is a dynamic and engaging application that I developed, inspired by the original Salt n Pepper platform. This clone serves as a vibrant space for users to explore, share, and enjoy culinary experiences, focusing on food discovery and community interaction.

  • Calculator

    Calculator is a versatile application that I developed to provide users with an intuitive and efficient tool for performing mathematical calculations. Designed with user experience in mind, this calculator combines functionality with a sleek interface.

  • Registration-Form

    Registration Form with Map is an innovative application that I developed, designed to streamline the user registration process while incorporating an interactive map feature. This form allows users to easily input their information and visually select their location.

  • Calendar

    Calendar is a versatile application that I developed to help users manage their schedules and important dates efficiently. This calendar combines functionality with a user-friendly design, making it easy for individuals and teams to stay organized.

  • Carousel

    Carousel is a dynamic image slider application that I developed to enhance visual storytelling and content presentation on websites. This carousel allows users to showcase multiple images or items interactively and engagingly.
